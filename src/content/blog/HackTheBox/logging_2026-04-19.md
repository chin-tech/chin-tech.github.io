## Overview

Logging is an assumed breach box, giving initial credentials. These allow us to inspect some SMB shares with an old password for a service account. Updating it to the current year gives us access, which allows us to perform a shadow credential attack on mhsa_health$. This gives us a shell on the box letting us see that's there a scheduled task running as another user which we can inspect the executable and reverse engineer it seeing that it loads up a DLL that we can hijack. Once doing so we can see that this user has access to the UpdateSrv certificate template wich allows us to request a server certificate and host a malicious WSUS server to get system on the box.
